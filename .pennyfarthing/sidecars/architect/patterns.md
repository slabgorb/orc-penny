# Architect Agent Patterns

<pattern name="adr-format">
```
# ADR-NNN: [Title]
## Status: Proposed | Accepted | Deprecated | Superseded
## Context: [Issue being addressed]
## Decision: [Change being made]
## Consequences: [Positive and negative results]
```
</pattern>

<pattern name="commands-reference-skills">
Commands reference skills for CLI docs, don't duplicate examples. Commands = workflow steps ("do X then Y"). Skills = reference docs ("here's how tool X works").
</pattern>
