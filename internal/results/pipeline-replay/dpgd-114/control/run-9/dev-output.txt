### Key Design Decisions

- **PluginId uses custom Deserialize** — validates namespace/name on deserialization, preventing CWE-20 serde bypass
- **PluginManifest uses private fields with getters** — enforces immutability after construction
- **RawEvent uses private fields with getters** — protects tenant_id from post-construction mutation
- **validate_config() uses jsonschema crate** — Null schema accepts anything, real schemas are compiled and validated
- **Sub-crate traits are standalone** (no AxiathonPlugin supertrait) — matches tests and spike pattern
