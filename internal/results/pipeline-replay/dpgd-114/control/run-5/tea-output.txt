1. **`PluginId::FromStr`** — stub always returns `Err("not implemented")` (5 tests catch this)
2. **`PluginId::Display`** — stub returns empty string (2 tests catch this)
3. **`PluginKind::Display`** — stub uses `Debug` format (`"Connector"`) instead of snake_case (`"connector"`) (6 tests)
4. **`PluginKind` serde** — missing `#[serde(rename_all = "snake_case")]` (4 tests)
