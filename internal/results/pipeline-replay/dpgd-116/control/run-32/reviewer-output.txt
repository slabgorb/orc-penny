### Devil's Advocate

**Assume this code is broken. What would go wrong?**

1. **An operator sets `AXIATHON_API_URL=""` in their CI env.** The `from_file_with_env()` path accepts empty strings from env vars (line 128-130) without checking emptiness. The `TryFrom<RawConfig>` path rejects empty URLs, but `from_file_with_env` bypasses it. The operator gets a `ClientConfig` with `api_url: ""`, and every HTTP request silently fails with an opaque reqwest error instead of a clear "api_url cannot be empty" message. This is a validation consistency bug.

2. **A malicious server returns `500 Internal Server Error` with a body containing a database connection string.** `map_http_status(500, body_text)` wraps it in `CliError::ServerError(body_text)`. The `#[error("server error: {0}")]` Display echoes it verbatim to the operator's terminal. The CWE-209 tests pass because they only check for "server" in the output. If the operator pastes the error in a Slack channel, the DB connection string is leaked.

3. **An operator's HOME directory is unset (e.g., systemd service).** `dirs::config_dir()` returns `None`. `default_config_path()` falls back to `PathBuf::from(".config")` — a relative path. The CLI silently resolves to `./config/axiathon/cli.toml` relative to CWD, potentially loading a config file planted by an attacker in the working directory.

4. **A developer adds a new command in Story 6.2.** They match on `Commands` exhaustively. Six months later, Story 6.3 adds another command. Because `Commands` lacks `#[non_exhaustive]`, the Story 6.2 code now fails to compile. This is the exact scenario `#[non_exhaustive]` prevents.

5. **JsonFormatter receives a row with 2 columns but headers has 3.** `zip()` silently drops the third header. The JSON output is missing a field with no error. An operator running `axiathon rules list --format json | jq .data[].severity` gets `null` instead of an error.

The devil's advocate uncovered items 1, 2, and 4 as confirmed issues. Item 3 is medium-concern defense-in-depth. Item 5 is a real silent data loss path.
