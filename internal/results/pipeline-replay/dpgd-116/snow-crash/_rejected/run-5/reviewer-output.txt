## Findings

### [HIGH] `is_secure()` is a lie — credentials leak over HTTP — `client.rs:73-77`

The `is_secure()` method hardcodes `return true` and its doc comment claims *"the client will not leak credentials over unencrypted connections"* and *"skips sending auth headers over plain HTTP."* This is false. `build_request()` at line 92-97 injects `Authorization: Bearer` headers regardless of whether the URL is `http://` or `https://`. The security test at `security.rs:181-189` passes **vacuously** because `is_secure()` always returns `true`:

```rust
assert!(client.is_secure() || client.base_url().starts_with("https"), ...);
//      ^^^^^^^^^^^^^^^^^^^^ always true — test never exercises the real condition
```

This is a credential-leaking vulnerability (sending bearer tokens in plaintext) combined with a misleading public API. Either enforce the documented behavior in `build_request()` or remove the false claims.

### [HIGH] Nightly fmt check fails — `config.rs:37`, `output.rs:74`

Per `gotchas.md`: *"Always include `cargo +nightly fmt --all --check` in the preflight. If it fails, flag it before approval."* Two formatting diffs exist. This blocks merge.

### [MEDIUM] `--format` accepts arbitrary strings — `cli.rs:29`

`format` is `Option<String>`, meaning `--format xml` or `--format garbage` will parse successfully. AC-4 specifies `--format table|json|csv`. This should use `clap::ValueEnum` to restrict to valid values at parse time, matching the `OutputFormat` enum.

### [MEDIUM] `RawConfig` silently ignores unknown fields — `config.rs:18-23`

Without `#[serde(deny_unknown_fields)]`, typos like `api_rul = "..."` in `cli.toml` are silently dropped and defaults apply. The user gets no warning that their config key was misspelled. This is the classic "config typo" silent failure. The `token` field being ignored is intentional (security), but other unknown keys should at minimum warn.

### [MEDIUM] `apply_cli_overrides` doesn't validate zero timeout — `config.rs:94-101`

`load_from_path` rejects `timeout = 0` from both file and env var, but `apply_cli_overrides` accepts zero via `if let Some(t) = timeout { self.timeout = t.min(MAX_TIMEOUT); }`. A user passing `--timeout 0` would silently get a zero-second timeout.

### [LOW] `assert!` panics for header injection instead of returning `Result` — `client.rs:31-35, 44-48`
