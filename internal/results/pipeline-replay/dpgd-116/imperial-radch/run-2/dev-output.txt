- **Gap** (non-blocking): Test file `global_flags.rs` has a compile error in `server_flag_has_env_var()` at line 160. The test calls `.collect()` on `&OsStr` returned by clap's `Arg::get_env()`, but `&OsStr` does not implement `Iterator`. This blocks all 19 tests in that file from compiling. The fix is to replace lines 160-164 with `let env = arg.get_env().expect("--server must have env"); assert_eq!(env.to_str(), Some("AXIATHON_SERVER"));`. The production code correctly sets `env = "AXIATHON_SERVER"` on the `--server` arg.
