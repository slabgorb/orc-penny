### Key Design Decisions

- **Security**: `CliError::ServerError` Display shows generic "server error", not internal details (CWE-209). Header injection prevented via `HeaderValue::from_str` validation (CWE-113). Tokens never loaded from config files.
- **Exit codes**: 0=success, 1=generic error, 3=auth (401), 4=authz (403). Clap handles 2=usage automatically.
- **Config precedence**: CLI flags > env vars > config file > defaults, via chained `with_env_override`/`with_cli_override` methods.
- **`#[non_exhaustive]`** on `CliError` for future extensibility.
