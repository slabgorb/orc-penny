## Key Design Decision (from Party Mode brainstorm)

The solution is a **project-local shim** at `.pennyfarthing/bin/pf` generated by `pf init`:

**Monorepo/dogfooding shim:**
```bash
#!/usr/bin/env bash
exec /usr/bin/python3 "/abs/path/to/pennyfarthing-dist/src/pf_launcher.py" "$@"
```

**Installed user shim:**
```bash
#!/usr/bin/env bash
exec "/abs/path/to/.local/bin/pf" "$@"
```

Hook commands become: `.pennyfarthing/bin/pf hooks session-start` (stable, never change).
System python3 (/usr/bin/python3) + pf_launcher.py handles all resolution. Verified working in stripped `env -i` subprocess.
