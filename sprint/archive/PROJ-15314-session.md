## Story Description

Project hook scripts (setup-env.sh, auto-load-sm.sh, etc) generated by init/update during installation are sometimes created with 644 permissions instead of 755, which causes "Permission denied" failures when scripts are executed on session start.

## Acceptance Criteria

1. Generated hook scripts in `.pennyfarthing/project/hooks/` must be created with execute permission (755)
2. Both init and update commands must ensure proper permissions
3. Migration of hooks from old locations must preserve execute permission
4. Session start must not fail due to permission issues on hook scripts
